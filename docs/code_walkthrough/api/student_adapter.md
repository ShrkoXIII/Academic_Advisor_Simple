# تحويل الطالب إلى لقطة بداية الفصل

```text
src/api/student_adapter.py
```

هذه الصفحة تصف الشفرة الموجودة في النسخة المفحوصة. الشفرة لم تُشغّل لتوليد توصية أو تدريب أثناء إعداد الشرح.

[العودة إلى مسار التعلم](../00_START_HERE.md)

## ١. لماذا يوجد هذا الملف؟

يحوّل الرد الجامعي إلى لقطة الطالب المطلوبة للتوقع دون تسريب نتيجة فصل الهدف، ويشرح الميزات المتاحة والمفقودة بدل اختراع قيم لها.

الدور في الخريطة:
واجهة وتشغيل

تصنيف الاستعمال:
نشط في مسار خدمة أو بناء أو تقييم أو أداة موثقة

## ٣. المدخلات

غلاف الرد الأصلي وسياق الطالب والهوية المستهدفة؛ معلومات بداية الفصل والدبلوم وملخص الفصول السابقة. قد يتضمن سياق التكامل مقامًا رسميًا موثقًا أو قيمًا مكملة بمصدر وفصل.

تواقيع الجدول أدناه مأخوذة من تعريفات الملف. نوع أو دلالة حقل لا يظهر في التوقيع يُفسر من الحسابات وشروط التحقق، ولا يفترض من الاسم وحده.

خريطة حقول المصدر المباشرة:

```json
{
  "faculty_id": "FACULTY_ID",
  "grade_version_id": "GRADE_VERSION_ID",
  "start_agpa_points": "START_AGPA_POINTS",
  "start_total_in_courses": "START_TOTAL_IN_COURSES",
  "start_total_in_credits": "START_TOTAL_IN_CREDITS",
  "degree_credits_count": "DEGREE_CREDITS_COUNT"
}
```

الأنواع والبنى المستعملة في هذا الحد:

```text
request: dict
settings: ApiSettings
grade_scale: GradeScale | None
```

## ٤. المخرجات

نتيجة تحقق تحمل لقطة مطبّعة وقائمة النواقص والفحوص والمصدر. عدم توفر أصل لازم لفحص محدد يجعل النتيجة جزئية، بينما التعارض أو المصدر الزمني غير المقبول ينتج خطأ.

مخرجات كل تابع التي تعاد صراحةً تظهر في جدول التعريفات. التعبير المعروض مقتطف من مسار إرجاع فعلي؛ ليس بديلًا عن شروط الوصول إليه.

أنواع المخرجات الأساسية:

```text
adapt_student(...) -> ValidationResult
normalized -> dict
number(...) -> Decimal | None
```

### تسلسل المنطق وأسباب الخطوات

خطوة 1:

```text
adapt_student
```

يربط سياق الجلب بالطلب ثم يفحص هوية الرد وتفاصيل الاختصاص قبل الحساب.

خطوة 2:

```text
_official_gpa_credits
```

يثبت أن قيمة التسجيل التراكمية تخص بداية الهدف؛ أو يطرح مساهمة الفصل فقط مع شهادة اكتمال وجمع إضافي وقيمة رسمية للساعات المحتسبة.

خطوة 3:

```text
_history
```

يفحص هوية كل صف وفصله، ويمنع الهدف والمستقبل ثم يبني جدولًا مطابقًا للأعمدة المتاحة.

خطوة 4:

```text
add_student_history_features / compute_student_gpa_history
```

يستعمل الحساب الأصلي الكامل عند اكتمال أعمدته، وإلا الحساب المشترك الممكن فقط؛ لا يحاكي أعمدة ناقصة.

خطوة 5:

```text
sourced
```

يراجع مصدر القيم المكملة وحدها الزمني، ويرفض تعارضها مع بيانات مثبتة.

خطوة 6:

```text
GradeScale.validate_versions
```

يفحص نسخة سلم العلامات عند توفره؛ غيابه فحص غير متاح وليس إثبات توافق.

### خريطة المقام والمصادر

قيمة الإكمال السابق تخص ساعات النجاح ولا تستعمل مقامًا.

```text
START_TOTAL_IN_CREDITS -> start_total_in_credits
TOTAL_REG_CREDITS -> current_gpa_credits / prior_total_reg_credits
START_AGPA_POINTS -> start_agpa_points
```

المقام الرسمي لبداية الفصل يحتاج شهادة توقيت هدفها مطابق وقطعها الفصل السابق. في نهاية الفصل، لا تكفي الساعات المسجلة؛ يلزم عداد رسمي للساعات المحتسبة مع اكتمال وقاعدة جمع إضافية.

```python
prior_gpa_credits = TOTAL_REG_CREDITS - semester_gpa_counted_credits
```

هذه صيغة تعليمية للاشتقاق المسموح، وليست تعويضًا عن الشهادة. إن غيرت الإعادة أو الاستثناء جودة الماضي أو مقامه بصورة غير إضافية، لا تقبل هذه الطريق.

فحص التاريخ يتحقق من كل هوية قبل الإعلان أن الأعمدة جزئية. بعض الأعمدة المفقودة يقبلها عقد المودل كفقدان، أما الفجوات ومخطط التاريخ اللازم للتوصية فلا يسمح بغيابهما.

شروط تحكم فعلية للتابع التالي؛ يتحدد أثرها من تسلسل التحقق المشرح:

## ٦. كيف تتغير البيانات؟

إذا كان الإجمالي النهائي ١٢٩ وساعات التسجيل ١٨ فلا يستنتج المحول ١١١ وحده. يصبح الطرح صحيحًا فقط عند توثيق أن ١٨ مساهمة كاملة محتسبة في المعدل تحت قواعد جمع إضافية.

## ٧. القواعد والافتراضات

ساعات الإكمال السابقة ليست مقام المعدل. قيمة التسجيل بعد نهاية الفصل لا تعني بداية الفصل. الدبلوم ومصدر مقام المعدل لازمَان؛ الفصول غير المسجلة لا تتحول إلى تسجيلات مصطنعة.

- القواعد الأكاديمية المؤكدة يُصرح بها عند توفر مصدرها؛ وجود شرط في الكود لا يمنحه اعتمادًا جامعيًا جديدًا.
- السياسات القابلة للإعداد والمصادر الخارجية يجب قراءتها مع صفحة الخدمة أو التدريب بحسب المسار.
- الدقة العددية والتفرد وترتيب الفصول افتراضات تقنية يفحصها الملف أو حدوده المجاورة.

## ٨. مخاطر التسرب والصحة

نسخ نتيجة الهدف إلى سلسلة المعدلات السابقة تسرب مباشر. حذف الفصول غير المسجلة يغيّر الفجوات. استعمال إجمالي نهاية الفصل مقامًا سابقًا يغيّر المعدل المتوقع وميزة التسجيل السابقة.

أي قيمة أو قطع غير مطابق يجب أن يرفض أو يسجل غير متاح حسب العقد، قبل تحويله إلى توقع. لا تعالج هذه الصفحة نقص المصدر بتغيير ميزة أو وضع قيمة افتراضية.

## ١١. القيود المعروفة

توقيت إجمالي التسجيل في تصدير التدريب ما زال يحتاج تأكيد الجامعة. المحول يطبق عقد بداية الفصل لكنه لا يعيد تعريف ميزات التدريب أو يعيد تدريبها.

العلاقات المستخرجة من الاستيراد لا تثبت حركة طلب حي. تم تمييز مسار الخدمة والبناء والتقييم والتجربة من المستدعين ونقاط التنفيذ، لا من وجود الملف فقط.

## ١٢. مراجعة سريعة

ثلاث خلاصات:

- ساعات النجاح السابقة لا تصلح مقامًا للمعدل.
- كل صف تاريخي يفحص بهويته ووقته قبل حساب الميزات.
- التاريخ الجزئي يستعمل الحساب الممكن ويعلن الباقي غير متاح.

ثلاثة أسئلة للفهم:

1. ما الدليل الذي يجعل إجمالي التسجيل قيمة بداية موثوقة؟
2. لماذا لا يكفي طرح ساعات الهدف من إجمالي نهاية الفصل؟
3. كيف تتغير دلالات الفجوات إذا حذفت الفصول غير المسجلة؟

تمرين قراءة آمن:

ابدأ بإجمالي نهائي قدره ١٢٩ وساعات هدف قدرها ١٨، واكتب الأدلة الناقصة التي تمنع اشتقاق ١١١ تلقائيًا.

التمرين قراءة وحساب على الورق؛ لا يغير المشروع ولا يشغّل بناءً أو توقعًا أو تحديث تاريخ.
